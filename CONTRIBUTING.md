
# Contribution Guidelines

## Getting Started
1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature/fix
4. Make your changes
5. Commit and push your changes
6. Submit a pull request

## Code Style
- Follow Prettier and ESLint rules
- Use consistent indentation (2 spaces)
- Write clear, concise, and well-documented code

## Testing
- Write tests for new features
- Ensure existing tests pass
- Update test coverage documentation

## Pull Request Process
1. Ensure your branch is up to date with the main branch
2. Run all tests locally
3. Submit a pull request with a clear description
4. Address any feedback from reviewers

## Documentation
- Update README.md with any new features
- Add documentation for new APIs
- Keep documentation up to date

## Reporting Issues
- Use GitHub Issues to report bugs or suggest features
- Provide detailed steps to reproduce the issue
- Include expected and actual behavior

## License
- All contributions must be made under the MIT License
- Ensure you have the right to contribute the code

## Community
- Be respectful and inclusive
- Follow the code of conduct
- Participate in discussions and reviews
